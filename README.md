## 🚀 Как запустить проект

### 1. Клонировать репозиторий
```bash
git clone https://github.com/username/form.git
cd form
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Создать файл .env

В корне проекта:

```
RESEND_API_KEY=ваш ключ
PORT=3000
```

RESEND_API_KEY нужно будет создать на сайте resend.com  
Чтобы отправлять не только на свой mail нужно будет вам создать свой домен, подключить его на resend.com и тогда все заработает

### 4. Запуск сервера
```bash
npm start
```

### 5. Открыть проект

Frontend:
```
index.html
```

## Как работает форма

Пользователь заполняет форму:
- имя
- телефон
- email
- комментарий

На фронтенде происходит валидация данных  
Данные отправляются на сервер (POST /form)

Backend:
- проверяет данные
- отправляет письмо администратору
- отправляет копию пользователю

## Логика backend

- Express обрабатывает маршрут `/form`
- Данные валидируются
- Используется Resend API для отправки email
- Отправляются 2 письма:
  - администратору
  - пользователю
